# Security Policy

## Supported Versions

Currently, the `main` branch and the latest stable release are supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within `soc-chronicle`, please DO NOT open a public issue.
Instead, please send an email to the repository maintainers or use GitHub's private vulnerability reporting feature (if enabled on the repository).

We will triage the vulnerability and provide a timeline for a patch. Once patched, we will publicly disclose the vulnerability to ensure users can update.

Thank you for helping keep `soc-chronicle` secure!
